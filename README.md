# ESSIMPLEX staging

Private test copy of the ESSIMPLEX site. Not published: no GitHub Pages, no custom domain, noindex.
Preview locally: `python3 -m http.server 8080`

## Redesign branch
`redesign` rebuilds the site per `DESIGN.md`. Pages are generated by `python3 tools/build.py` (header, footer and trace SVGs are shared); edit the script, not the HTML, then rebuild. `baseline-v1` tags the previous design on main.
